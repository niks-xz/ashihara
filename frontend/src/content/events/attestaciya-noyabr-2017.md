25 ноября 2017 года в Краснодаре прошёл ежегодный аттестационный экзамен по Ашихара-каратэ. Спортсмены демонстрировали технику кихон, идо, ката, кондицию на снарядах и физическую подготовку.

Для претендентов на высокие пояса программа включала поединки по одной минуте со свежими соперниками: для 4 кю - 5 поединков, для 3 кю - 8 поединков.
